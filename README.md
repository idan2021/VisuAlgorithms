# VisuAlgorithms — מעבדת אלגוריתמים

## פתיחה ב־Microsoft Edge

פתחו את `index.html` בלחיצה כפולה או גררו אותו לחלון Edge. אין צורך להתקין תוכנות, להריץ פקודות או להפעיל שרת.

בפתיחה הראשונה נדרש חיבור לאינטרנט כדי לטעון את Preact ואת Babel מ־unpkg. הגופנים נטענים מ־Google Fonts; אם הם לא זמינים, האתר משתמש בגופני ברירת מחדל.

## מה כלול

- 19 הדמיות: BFS, DFS, דייקסטרה, בלמן־פורד, פלויד־וורשל, קרוסקל, פרים, A*, האלגוריתם ההונגרי, גייל־שפלי, חיפוש בינארי וליניארי, מיון בועות, הכנסה, בחירה, מיזוג, מהיר, TimSort ו־Quickselect.
- מעקב שורה־אחר־שורה לפי צעדי האלגוריתם, כולל הדגשה חוזרת של לולאות, צעדים קדימה ואחורה, והפעלה במהירויות שונות.
- תצוגת גרף, התאמות דו־צדדיות ומערכי מיון/חיפוש שמתאימים את עצמם לגודל החלון.
- דף מציאת נתיבים עם ציור קירות בגרירה, הזזת נקודת ההתחלה והיעד, ויזואליזציה של דייקסטרה, A*, BFS ו־DFS, סיבוכיות זמן ומדידת זמן החיפוש עד ליעד.
- צביעת תחביר לקוד, כולל מילות מפתח, פונקציות, טיפוסים ומחרוזות; קטעי קוד ב־C# נוספו לצד השפות הקיימות.
- מיתוג VisuAlgorithms בכיוון „קוד ונתונים”, כולל קובצי SVG ללוגו ולאייקון הדפדפן.
- קטעי קוד ב־Python, JavaScript, TypeScript, Java, C++, C#, Go ו־Rust.
- ממשק בעברית, אנגלית, ערבית, ספרדית, צרפתית וגרמנית.
- שליטה בצמתים ובקשתות, מהירות, צעדים, פלטות צבעים והדמיה חיה.
- בחירת אלגוריתם ישירות ממעבדת הבית, עם Auto-Play אופציונלי להדמיות.
- דפי המעבדה, הספרייה ומציאת הנתיבים רשומים בהיסטוריית הדפדפן (Back/Forward).
- Auto-Play זמין גם במעבדת הנתיבים; תוויות האלגוריתמים והפקדים בספרייה מתורגמים בכל שש שפות האתר.

`src/` מכיל את גרסת המקור של האפליקציה. לפתיחה ישירה ב־Edge השתמשו ב־`index.html`, שמכיל את האפליקציה ואת העיצוב בקובץ יחיד.
