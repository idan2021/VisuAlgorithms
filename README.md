# VisuAlgorithms

**מעבדת אלגוריתמים אינטראקטיבית** — צופים באלגוריתם, בקוד ובנתונים שלו מתקדמים יחד, צעד אחר צעד.

VisuAlgorithms הוא אתר לימודי שנבנה ב־Preact. הוא מדגים אלגוריתמי גרפים, חיפוש, מיון ושידוך, וכולל סביבת ניסוי למציאת נתיבים על גבי רשת שניתן לערוך.

## תכונות

- **הדמיה וסנכרון קוד:** שורת הקוד הפעילה מודגשת בהתאם לצעד הנוכחי באלגוריתם. לולאות מוצגות בכל איטרציה, ולא רק פעם אחת.
- **ספריית אלגוריתמים:** BFS, DFS, דייקסטרה, בלמן־פורד, פלויד־וורשל, קרוסקל, פרים, A*, האלגוריתם ההונגרי, גייל־שפלי, חיפוש בינארי וליניארי, וכן אלגוריתמי מיון ו־Quickselect.
- **שפות תכנות:** קטעי קוד ב־Python, JavaScript, TypeScript, Java, C++, C#, Go ו־Rust.
- **מעבדת נתיבים:** יצירת קירות בגרירה, הזזת נקודות התחלה ויעד, השוואת Dijkstra/A*/BFS/DFS, צפייה בסיבוכיות ובזמן החיפוש.
- **שליטה בהרצה:** הפעלה, השהיה, איפוס, צעדים, מהירות ו־Auto-Play.
- **התאמה אישית:** בחירה מתוך פלטות צבעים, שינוי מספר הצמתים והקשתות והתאמה למסכים בגדלים שונים.
- **ממשק רב־לשוני:** עברית, אנגלית, ערבית, ספרדית, צרפתית וגרמנית, כולל סידור RTL/LTR.
- **ניווט:** המעבדה, ספריית האלגוריתמים ומעבדת הנתיבים מקושרות לכתובות hash נפרדות. כפתורי Back ו־Forward בדפדפן מחזירים בין הדפים.

## התחלה מהירה

דרישות: Node.js 22 ומנהל החבילות npm.

```bash
npm ci
npm run dev
```

Vite יציג כתובת מקומית בטרמינל. פתחו אותה ב־Edge, Chrome או Firefox.

פקודות שימושיות:

```bash
npm run build    # יצירת אתר סטטי בתיקיית dist/
npm run preview  # הצגת גרסת הייצור המקומית
```

## שימוש באתר

1. בחרו אלגוריתם מתוך הבורר בראש המעבדה או מתוך ספריית האלגוריתמים שבתפריט.
2. בחרו את שפת התכנות כדי להציג את מימוש הקוד המתאים.
3. לחצו על הפעלה, או עברו בין צעדים בעזרת ציר הזמן. הפעילו Auto-Play אם רוצים שההדמיה תחזור אוטומטית.
4. שנו את מספר הצמתים, הקשתות, המהירות או פלטת הצבעים באזור ההגדרות.
5. במעבדת הנתיבים, ציירו מכשולים על הרשת, הזיזו את ההתחלה והיעד, בחרו אלגוריתם ולחצו על מציאת מסלול.

במעבדת הנתיבים שעון החיפוש נמדד בזמן חישוב המסלול ונעצר ברגע שהאלגוריתם שולף את היעד מהחזית. אם אין מסלול, המדידה מסתיימת כשהחזית מתרוקנת.

## מבנה הפרויקט

```text
.
├── index.html                         # מעטפת האתר ונקודת הכניסה של Vite
├── edge-standalone.html               # גרסה עצמאית לפתיחה ישירה ב־Edge
├── src/
│   ├── main.jsx                       # מצב משותף, ניווט, תפריט ושילוב הדפים
│   ├── style.css                      # עיצוב משותף ורספונסיבי
│   ├── components/
│   │   ├── Icon.jsx                   # אייקונים לשימוש חוזר
│   │   └── AlgorithmVisuals.jsx       # גרף, מיון, שידוך והצגת קוד
│   └── pages/
│       ├── LabPage.jsx                # מעבדת האלגוריתמים הראשית
│       ├── AlgorithmLibraryPage.jsx   # ספריית האלגוריתמים
│       └── PathfindingPage.jsx        # מעבדת מציאת הנתיבים
├── .github/workflows/deploy.yml       # בנייה ופרסום אוטומטיים ב־GitHub Pages
├── CHANGELOG.md                       # יומן שינויים
└── vite.config.js                     # הגדרות בנייה ונתיבים יחסיים לאירוח סטטי
```

`main.jsx` מחזיק את מצב האפליקציה המשותף ומרכיב את מעטפת האתר; כל דף ותצוגה ייעודית נמצאים בקובץ נפרד. רכיבים אלה נטענים בתוך אותה אפליקציית Preact כדי לשמור על שפה, בחירות ותפריט משותפים.

## למה יש `index.html` אחד

האתר הוא SPA (אפליקציית עמוד יחיד): הדפדפן טוען את `index.html` פעם אחת, ו־Preact מרכיב את הדף המתאים מתוך `src/pages/`. זו בחירה מתאימה כאן, משום שהכותרת, תפריט הצד, השפה והגדרות ההדמיה משותפים לכל המסכים. מעבר בין המעבדה, הספרייה ומעבדת הנתיבים מעדכן את הנתיב (`#/lab`, `#/algorithms`, `#/pathfinding`) ואת היסטוריית הדפדפן, בלי לטעון מסמך חדש.

המשמעות היא שאין צורך בקובץ HTML נפרד לכל מסך. הפרדה לקובצי רכיבים שומרת את הקוד של כל דף ברור ונוח לתחזוקה, בעוד `index.html` נשאר נקודת הכניסה הראשית.

## פתיחה ישירה ב־Edge

לפתיחה בלחיצה כפולה, ללא התקנת Node.js או הרצת שרת, פתחו את `edge-standalone.html`. זו גרסה עצמאית ששומרת את חוויית השימוש הקודמת. בטעינה הראשונה נדרש חיבור לאינטרנט כדי להביא את Preact ואת Babel מ־CDN; הגופנים נטענים מ־Google Fonts.

לפיתוח ולפרסום, השתמשו ב־`index.html` דרך Vite. גרסה זו טוענת את הקומפוננטות המופרדות מתוך `src/`.

## פרסום ב־GitHub Pages

הקובץ `.github/workflows/deploy.yml` בונה את האתר ומפרסם אותו ב־GitHub Pages לאחר כל push לענף `main`. הוא גם מאפשר הרצה ידנית מתוך לשונית Actions.

לאחר העלאת הפרויקט ל־GitHub:

1. פתחו **Settings → Pages** במאגר.
2. בחרו **GitHub Actions** כמקור הפרסום.
3. ודאו ש־Actions מורשה לפרסם Pages אם GitHub מבקש זאת.
4. עקבו אחר ה־workflow `Build and deploy VisuAlgorithms`. כתובת האתר תופיע בסיום הפריסה.

כתובת האתר במאגר רגיל תהיה בדרך כלל `https://<owner>.github.io/<repository>/`. עדכונים לענף `main` ייבנו ויפורסמו מחדש אוטומטית.
